Ongoing app updates are handled by [Winget-AutoUpdate (WAU)](https://github.com/Romanitho/Winget-AutoUpdate), a community-maintained updater that `winget-app-install.ps1` sets up automatically at the end of every install run. There is nothing to enable and no flags to pass — if WAU is missing or older than the pinned version, the installer installs or upgrades it.

<Note>
  WAU replaces the homegrown scheduled-update feature from older versions of the script (`-EnableScheduledUpdates`, the `WingetAppSetup-ScheduledUpdates` task, toast notifications, and rollback scripts). Those parameters and files no longer exist. The uninstall script removes WAU and also cleans up any legacy scheduled-update task left by older versions.
</Note>

## How it runs

| Setting | Value |
|---|---|
| Scheduled task | `Winget-AutoUpdate` under the task path `\WAU\` |
| Schedule | Weekly, 2:00 AM |
| Account | SYSTEM — updates apply machine-wide |
| User-context pass | Yes — an additional pass runs for the logged-on user |
| WAU self-update | Disabled — the version stays pinned |

Running as SYSTEM machine-wide (plus the user-context pass) avoids the cross-user `0x80073d19` failures that a per-user scheduled task hits when a different user is logged on at run time.

## Version pinning

The installer deploys a **pinned, SHA256-verified** WAU release rather than "latest", so every machine runs a known-good updater version. WAU's own self-update is disabled to keep it that way. The pin lives in `Get-WauPin` (`WingetAppSetup/Public/WingetAutoUpdate.ps1` in the repo) — bump it there to roll out a newer WAU. When the installer finds an existing WAU older than the pin, it upgrades it in place.

## Checking on WAU

```powershell
# Confirm the scheduled task exists
Get-ScheduledTask -TaskName "Winget-AutoUpdate" -TaskPath "\WAU\"

# See when it last ran and when it runs next
Get-ScheduledTaskInfo -TaskName "Winget-AutoUpdate" -TaskPath "\WAU\"
```

WAU writes its own logs and configuration under its install location; see the [WAU documentation](https://github.com/Romanitho/Winget-AutoUpdate) for its log paths, notification options, and include/exclude lists.

## Removing automatic updates

Run the companion uninstall script — it uninstalls WAU (via its real product code) along with the curated apps, and removes any legacy scheduled-update task from older installer versions:

```powershell
pwsh -ExecutionPolicy Unrestricted -File .\winget-app-uninstall.ps1
```
